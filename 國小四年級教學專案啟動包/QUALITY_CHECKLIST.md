# 影片與首頁上線前品質檢查表

## 教材與正確性

- [ ] 已完整讀取使用者指定的課本、講義或自修，而非只看課名。
- [ ] 學習目標符合國小四年級程度，沒有不必要的高年級延伸。
- [ ] 名詞、數字、算式、答案、單位、年代、地名與因果已逐一核對。
- [ ] 例題不是只報答案，每一步都有理由。
- [ ] 已處理學生最可能出現的錯誤概念。

## 教學設計

- [ ] 開頭以熟悉情境提出明確問題。
- [ ] 一支影片聚焦一個主要概念，資訊量沒有過載。
- [ ] 使用具體操作 → 圖像 → 符號或規則的順序。
- [ ] 至少有一次要求學生預測、回答或暫停思考。
- [ ] 結尾讓學生主動回想 3–4 個重點。
- [ ] 實際長度與內容相稱，沒有為湊時間而重複。

## 角色、畫面與動畫

- [ ] 小甯、小霖的臉型、髮型、服裝、名稱與配色一致。
- [ ] 角色有合理的表情、視線、手勢與情境反應。
- [ ] 關鍵概念以連續動作或視覺因果呈現，不像播放 PowerPoint。
- [ ] 同一時間只有一個主要視覺焦點。
- [ ] 旁白提到的物件與變化會同步出現。
- [ ] 畫面沒有錯誤標示、穿幫、浮水印或不相關元素。
- [ ] 手機尺寸仍看得清楚所有重要文字與圖像。

## 旁白、字幕與聲音

- [ ] 使用自然臺灣中文口音；指定聲音與角色相符。
- [ ] 語速、停頓、語氣自然，沒有明顯機器人式朗讀。
- [ ] 開頭無聲約不超過 0.5 秒，一般轉場無聲約不超過 0.6 秒。
- [ ] 互動題有清楚標示的思考時間，不會誤認為斷音。
- [ ] 背景音樂與音效沒有蓋過人聲。
- [ ] 字幕逐句符合實際旁白，沒有漏句、搶字或延遲。
- [ ] 全部使用臺灣繁體中文，沒有簡體字、舊角色名或錯別字。

## 技術輸出

- [ ] 影片為 16:9、1920×1080、H.264 MP4。
- [ ] 音訊為 AAC 48 kHz，左右聲道或單聲道播放正常。
- [ ] 從頭到尾試播完成，沒有黑畫面、花屏、破音或突然截斷。
- [ ] 已抽查開頭、每個轉場、代表例題、互動題與結尾。
- [ ] 影片與大型製作素材位於 `local-content/`，未被 Git 追蹤。

## YouTube 與首頁

- [ ] YouTube 影片標題、縮圖與網址正確，播放權限符合預期。
- [ ] repository 根目錄的 `../data/lessons.js` 科目、單元、標題、標籤、網址與狀態正確。
- [ ] 已直接開啟 repository 根目錄的 `../index.html`，課程卡片與數量顯示正確。
- [ ] 已點擊新卡片，確認另開 YouTube 且網址正確。
- [ ] 手機版首頁沒有文字溢出或卡片破版。
- [ ] 只有在使用者明確要求後才提交或推送 GitHub。
