# 本機大型素材區（不提交 GitHub）

此資料夾用來放課本、參考資料、製作中的聲音、影格與影片。`.gitignore` 會排除內容，只保留本說明檔。

建議每一課使用以下結構：

```text
local-content/
├── references/
│   └── 科目／單元／課本與講義.pdf
└── videos/
    └── 科目／單元／
        ├── audio/
        ├── frames/
        ├── project/
        └── output/
```

完成影片請上傳 YouTube，首頁只保存 YouTube 連結。請勿把輸出 MP4、旁白音檔或教材 PDF 搬到 GitHub 可追蹤的資料夾。
