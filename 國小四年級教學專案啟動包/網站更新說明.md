# 首頁課程更新說明

首頁會讀取 `data/lessons.js`。因此影片上傳 YouTube 後，只需要修改該檔案，不必複製整張課程卡片的 HTML。

## 新增已上線課程

在 `window.LESSONS` 陣列加入一筆：

```js
{
  grade: "四年級",
  subject: "數學",
  unit: "2-3",
  title: "課程名稱",
  youtube: "https://youtu.be/請填入影片代碼",
  tags: ["關鍵概念", "動畫例題"],
  status: "published"
}
```

`subject` 必須使用首頁已有的名稱：`數學`、`國語`、`自然` 或 `社會`。`status` 是 `published` 時會成為可點擊的 YouTube 卡片；使用 `planned` 時則顯示「準備中」。

## 上線前測試

1. 儲存 `data/lessons.js`。
2. 直接雙擊或以瀏覽器開啟 `index.html`。
3. 確認課程出現在正確科目，單元數量正確。
4. 點擊卡片，確認另開的 YouTube 網址正確。
5. 縮窄視窗模擬手機，確認文字與卡片未超出畫面。

## 改 GitHub 網址

搜尋 `index.html` 中的 `https://github.com/USERNAME/elementary_school`，換成新專案網址。

影片、旁白與教材不要放入首頁資料夾；只保留 YouTube 連結即可。
